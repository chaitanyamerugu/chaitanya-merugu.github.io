Machine Learning Algorithm Types

A visual framework for how each algorithm learns, the data domain it serves, and the real-world systems it powers.

The organizing idea

Start with the data

The first decision is whether examples have known answers. Supervised learning maps inputs to labeled outcomes; unsupervised learning discovers structure when no answer key is provided.

The larger landscape

AI → ML → deep learning

Artificial intelligence is the broad field. Machine learning learns patterns from data, while deep learning uses many-layered neural networks. Generative AI extends these models to create text, images, audio, and code.

Family 1 · Learns from labeled data

Supervised learning

Every training example carries the correct answer, such as a price, class, or label. The model learns the mapping from input to answer, then predicts answers for new data.

Tabular data

Linear regression

Fits a line that minimizes error between predicted and actual values.

  • Revenue forecasting
  • Home price estimation
Tabular data

Decision tree

Asks a chain of yes/no questions to separate classes or predict values.

  • Loan approval
  • Patient triage
Tabular data

Random forest

Combines many decision trees by majority vote or averaged prediction.

  • Fraud detection
  • Customer churn
Tabular data

Gradient boosting

Builds small trees sequentially, correcting the errors of earlier trees.

  • Risk scoring
  • Search ranking
Tabular · NLP · vision

Support vector machine

Finds the boundary with the widest margin between classes.

  • Spam filtering
  • Digit recognition
Computer vision

Convolutional neural network

Slides learned filters across images to recognize edges, textures, and objects.

  • Medical screening
  • Defect inspection
Family 2 · Learns from unlabeled data

Unsupervised learning

No answers are provided. The model discovers groups, compressed representations, or generative structure on its own.

Tabular · vision

K-means clustering

Assigns examples to the nearest center and moves centers until groups stabilize.

  • Customer segmentation
  • Image color compression
Tabular · vision

Principal component analysis

Rotates data onto axes that preserve the most variation with fewer dimensions.

  • Feature reduction
  • 2D visualization
Vision · generative AI

Autoencoder

Compresses inputs and reconstructs them, retaining the most essential features.

  • Anomaly detection
  • Image denoising
NLP · generative AI

Transformer

Uses attention so each token can weigh the importance of every other token.

  • Code generation
  • Summarization
Generative AI

Generative adversarial network

Trains a generator and discriminator together to produce increasingly realistic samples.

  • Super-resolution
  • Synthetic data
Generative AI · vision

Diffusion model

Learns to remove noise step by step, starting from random noise to generate new content.

  • Image generation
  • Photo editing
How to choose

From problem shape to model family

01

Do labels exist? Use supervised learning when the goal is prediction; use unsupervised learning to discover groups or structure.

02

What is the data shape? Rows and columns favor tree ensembles. Pixels favor CNNs. Sequences of words favor transformers.

03

Is the output a decision or a creation? Most models discriminate between known outcomes; generative models learn the data itself so they can create new examples.

04

Balance clarity and power. Linear models and single trees are easier to explain. Deep networks can be more powerful but harder to interpret.
